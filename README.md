# Tools Project

A personal Django project that brings together a few handy tools in one place. The idea was to create a simple environment where users can quickly perform everyday tasks without switching between multiple websites.

## What's inside?

Right now the project includes two main tools.

**Python Online Editor**  
A simple interface for writing and running Python code directly in the browser. It uses Pyodide, which means the code runs entirely on the client side. This makes it useful for quickly testing small code snippets or experimenting with Python.

**File Conversion Tools**  
Basic tools for converting files between different formats. For example, users can upload a PDF file and convert it into a Word document. The goal is to keep the process simple and easy to use.

## How it works

The backend is built with Django and uses MySQL as the database.  
User authentication is handled using Django’s built-in authentication system.

The frontend is styled with Tailwind CSS together with standard HTML templates to keep the interface clean and responsive.

## Run it locally

Clone the repository, create a virtual environment, install the required dependencies, and run the Django development server.
